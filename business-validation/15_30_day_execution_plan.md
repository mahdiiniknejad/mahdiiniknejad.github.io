# 15 — 30-Day Execution Plan (for "Recover")

**Goal of the 30 days:** *Not* to build product. To get **paid evidence** that (a) owners will say yes to contingency revenue recovery, (b) recovery rates make the math work, and (c) which beachhead vertical is best. Spend ≈ $0–$200.

## Guiding rule
**No product code until 3 owners have paid on contingency.** Everything below is manual/concierge by design.

## Week 1 — Sharpen & set up
- [ ] **Pick 2 candidate beachhead verticals** to test in parallel (recommend: **auto repair** + **optometry** or **aesthetic/med-spa**; avoid dental first due to HIPAA).
- [ ] Write the one-line offer (file 14) and a one-page "found money" explainer.
- [ ] Build a target list of **40 owners** (20 per vertical) via local search, FB groups, trade forums, LinkedIn.
- [ ] Set up: a simple form/Calendly, a shared doc to log conversations, a basic LLM workflow (ChatGPT/Claude) for drafting messages, an SMS/email sending method (your own number/email at first).
- [ ] Draft the contingency pilot agreement (1 page; 20% of recovered revenue; opt-out/consent language).

## Week 2 — Conversations (the real research)
- [ ] **20 outbound messages/calls to owners.** Goal: **8–10 real conversations.**
- [ ] In each: confirm the leak is felt, ask how they handle declined estimates / lapsed customers today, ask what they'd pay to recover it. **Listen for the kill-threshold signals** (file 18).
- [ ] Offer the free "recovery audit": *"Send me an export — I'll tell you how much is recoverable, free."*
- [ ] Target: **3 audits accepted.**

## Week 3 — Deliver concierge recovery (prove the rate)
- [ ] For each audit shop: quantify "$X recoverable now."
- [ ] Convert ≥2 audits into **paid contingency pilots.**
- [ ] **Manually run recovery:** AI-drafted, owner-approved, personalised multi-touch follow-up to declined/lapsed customers. Book returns.
- [ ] Track precisely: messages sent, replies, bookings, **$ recovered**, **recovery rate**, hours spent.

## Week 4 — Measure, decide, reframe
- [ ] Tally recovered $ and invoice the contingency fee (**first revenue**).
- [ ] Compute per-vertical: recovery rate, $/account, hours/account → does contingency math beat your time?
- [ ] **Decision gate:**
  - **≥2 paid pilots with recovery rate that makes contingency pay → GREEN:** pick the winning vertical, start automating the concierge (move toward file 19 CTO scope).
  - **Interest but weak recovery/attribution → REFRAME:** switch beachhead or pivot to **#2 vertical collections** (cleaner attribution).
  - **<2 serious buying conversations from 20 targeted owners → KILL/REFRAME** the framing (per kill-threshold, file 18).

## Success metrics (30 days)
| Metric | Target |
|---|---|
| Owner conversations | ≥ 8 |
| Free recovery audits | ≥ 3 |
| **Paid contingency pilots** | **≥ 2** |
| First revenue | > $0 (any recovered-fee) |
| Recovery rate measured | Yes, per vertical |
| Beachhead vertical chosen | Yes |

## Kill metrics (stop/reframe)
- < 2 serious buying conversations from 20 targeted owners → the framing is wrong.
- Recovery rate too low to make 20% contingency beat your hourly time → economics don't work → pivot beachhead or to collections.

## What NOT to do in these 30 days
- ❌ Write product code / build a dashboard / a website beyond a form.
- ❌ Touch blockchain (not part of this business).
- ❌ Start with dental (HIPAA) or chase the voice-receptionist market.
- ❌ Build PMS integrations before the manual version is paid for.

## Next questions for the founder (answer via the pilots)
1. Which vertical recovers fastest and pays most reliably?
2. What's the real recovery rate per vertical, and does 15–25% contingency beat your time?
3. What's the #1 owner objection, and does human-in-the-loop resolve it?
4. Will owners convert from "done-for-you concierge" to "software + success fee"?
