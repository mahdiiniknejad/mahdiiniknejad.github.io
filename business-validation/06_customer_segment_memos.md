# 06 — Customer Segment Memos

**Agent:** Customer Segment. Define the best *first* customer for each survivor. Separate **user / buyer / decision-maker**.

---

## C1 — Diagnosed-revenue recovery (LEAD candidate)

**Best first segment:** Owner-operated, high-ticket, appointment/estimate-based service businesses with a *measurable backlog of lost revenue* and an owner who feels the leak personally.

| Attribute | Profile |
|---|---|
| Industry (beachhead options) | Independent **auto repair / collision**, **optometry**, **aesthetic/med-spa & elective health** (cash-pay, lower regulation), dental (highest WTP but HIPAA) |
| Company size | 1–5 locations; $500k–$5M revenue |
| Decision-maker & buyer | **The owner** (often also operator) — single decision-maker, fast sale, no procurement |
| Daily user | Front-desk / office manager (the AI offloads their worst task) |
| Budget owner | Owner; budget already exists (recall tools, ISAs, VAs, marketing) |
| Software stack | A PMS/POS/DMS system-of-record (Dentrix, RevolutionEHR, Tekmetric, etc.) holding the lost-revenue data |
| Buying trigger | "I know I'm leaving money on the table but the front desk never works the list" |
| Sales cycle | Short (days–weeks); owner-led |
| Acquisition channel | Vertical FB groups, trade forums, niche conferences, cold outreach, "we recovered $X for a shop like yours" |
| Trust requirement | Must trust the AI to message *their* customers in *their* voice → start human-in-the-loop |

**Why this segment first:** single decision-maker = fast sale; existing budget = proven WTP; contingency pricing = de-risked purchase; the pain is the owner's own money.

## N7 — Vertical collections

| Attribute | Profile |
|---|---|
| Beachhead | **Independent self-storage operators** (3–20 facilities) OR small **member associations** |
| Decision-maker/buyer | Owner / operations manager |
| User | Facility/site manager who spends 10–15 hrs/mo chasing delinquency |
| Trigger | Delinquency creep + lien-compliance fear (lawsuit exposure) |
| Channel | SelfStorageTalk, ISS, state self-storage associations |
| Trust | Compliance-sensitive (lien law) → product must be provably correct |

## N6 — Job-shop / field-service quoting

| Attribute | Profile |
|---|---|
| Beachhead | Small **CNC/machine/fabrication shops** (5–30 employees) OR **electrical/mechanical contractors** |
| Decision-maker/buyer | Owner / estimator |
| User | Owner or lone estimator doing RFQs nights/weekends |
| Trigger | Lost a big account to a faster quote; RFQ backlog |
| Channel | Practical Machinist, trade shows, MMS |
| Trust | Estimate accuracy = liability → human-approves every quote |

## C3 — Scope-creep capture

| Attribute | Profile |
|---|---|
| Beachhead | **Digital/marketing/web agencies** (5–30 people) — best-quantified pain (99%/$1–5k/mo), reachable, sophisticated buyers |
| Decision-maker/buyer | Agency owner / ops/finance lead |
| User | Account managers / project leads |
| Trigger | Margin shock at month-end; "we gave away $X again" |
| Channel | Agency communities (e.g., owner Slack/FB groups), agency-ops influencers |
| Trust | Must not damage *their* client relationships → product frames change orders diplomatically |

---

## Cross-cutting customer insight

For **all four**, the winning first customer is the same archetype: a **small, owner-led service business where one person is both the budget owner and the victim of the pain**, holds the relevant data in a system-of-record, and **already spends money on a worse fix.** This archetype enables a *fast, founder-led, contingency-friendly sale* — the only kind a solo founder can close without a sales team.
