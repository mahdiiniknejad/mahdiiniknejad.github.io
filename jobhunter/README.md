# How to use (from your phone)

1. Save this ZIP anywhere in your phone's Files app. That's fine — Claude Code
   doesn't read your phone storage directly; you attach the ZIP to the session.
2. Open Claude Code (mobile app) → new remote session.
3. Attach jobhunter.zip to your first message and say:
   "Unzip this, read CLAUDE.md, and follow it. Start by asking me the [TODO]
   fields in preferences.md, then run Stage 1."
4. Answer the TODO questions once (visa status, min pay, hours, start date).
5. Add the browser: type  claude mcp add playwright
6. Each evening: open queue.html it produces, tap through the ready
   applications (~30 sec each). 25/day = 100 in 4 days.

The agent scrapes, scores, tailors every CV+letter to each job description,
and pre-drafts form answers. You only approve and tap submit.
